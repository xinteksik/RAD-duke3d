This is a local alpha preparation, not a clearance to redistribute the linked firmware.
JFDuke3D/JFAudioLib contain GPL-2.0-or-later code; RAD/Circle and inherited glue use
GPL-3.0-or-later. JFBuild uses Ken Silverman's Build Source Code License with
noncommercial and distribution restrictions. The audit did not locate an explicit
exception covering this combined RAD/Circle executable. JFMACT grant coverage also
needs clarification. Shipping source alongside a binary does not resolve this issue.

Keep this release private until the necessary rights/exceptions are documented or
a compatible implementation replaces the conflicting components. No authors have
been contacted and no permission is implied by existing upstream releases.
Full texts are in LICENSES and the dependency sources; the revision-specific audit
is [06-LICENSE-REVIEW.md](06-LICENSE-REVIEW.md). No single project license is asserted.
